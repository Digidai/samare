Samare — third-party software and typefaces

The project LICENSE covers Samare's own code. Upstream libraries, fonts,
and drawings retain their respective notices and licenses. Paths below are
relative to this source tree. The app bundles these resources under
Contents/Resources, with the same subdirectory names.

Offline document renderer

Resources/vendor/versions.json lists versions of the editor libraries. The
npm tarball URLs and integrity digests are in package-lock.json. The entry
point for the editor bundle is tooling/vendor/editor-entry.mjs. To reproduce
the browser assets with Node.js 22 and npm, run from the repository root:

    npm ci
    npm run vendor

These commands build the editor, assemble the Prism grammars and copy the
published diagram, YAML, diff, and font assets. Resources/vendor/sha256.json
records hashes of generated browser assets. Prebuilt copies allow a normal
macOS build without Node.js.

Native updates and local services

• Sparkle 2.9.6 and its bundled components retain their upstream notices.
  The build verifies the release archive identified in Updates/dependency.sh
  and copies its complete LICENSE into Contents/Resources/Updates/Sparkle-LICENSE.
  Source: https://github.com/sparkle-project/Sparkle/tree/2.9.6
• The local services run on CPython 3.13.18 from python-build-standalone
  release 20261110. Updates/python-runtime.sh pins the archive for each
  supported architecture and the notices archive. The app bundles the
  CPython history and terms, PSF license and dependency notices in
  Contents/Resources/Runtime/licenses/. The dependency catalog gives source
  URLs and build-level hashes for the upstream C libraries.
  https://github.com/python/cpython/tree/v3.13.18
  https://github.com/astral-sh/python-build-standalone/tree/20261110
  https://github.com/astral-sh/python-build-standalone/blob/20261110/pythonbuild/downloads.py
